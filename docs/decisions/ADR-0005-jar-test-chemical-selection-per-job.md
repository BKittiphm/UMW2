# ADR-0005: เลือกสารเคมีหนึ่งรายการต่อประเภทในงาน Jar Test

- Status: Accepted; amended 2026-09-29
- Date: 2026-09-25; amended 2026-09-29
- Scope: Jar Test chemical selection (TO-BE)

## Context

UMW เดิมเลือกสารก่อนเริ่มรอบทดลองและเลือกได้สูงสุดหนึ่งรายการต่อประเภท แต่ร่าง `jar_test_chemical_doses` ที่ unique ตามบีกเกอร์กับสัญญา ยังยอมให้สารคนละรายการในประเภทเดียวกันปรากฏในงานเดียว เช่น PAC กับสารส้ม การมีหลายสัญญาของ PAC เดียวกันเป็นความต่างด้านผู้ขาย/ราคา ไม่ใช่ความต่างของตัวสาร

## Decision

1. งาน `jar_tests` เลือกสารหนึ่งรายการต่อ `jar_chemical_type` ใน `jar_test_selected_chemicals` และใช้สารรายการเดิมทุก `jar_test_rounds` และทุกบีกเกอร์ของงาน
2. รายการที่เลือกอ้าง `site_chemicals` ของ Site เดียวกับงาน โดยต้องเปิดใช้งานและมีบทบาทที่ตรงกับ `chemical_type_mappings` ตอนเลือก
3. บังคับ `UNIQUE (jar_test_id, chemical_type_id)` ในรายการสารที่เลือก; `jar_test_chemical_doses` และ `jar_test_final_chemical_doses` อ้างรายการที่เลือกในงานเดียวกัน
4. Dose เปลี่ยนได้ตามรอบ/บีกเกอร์ แต่หนึ่งบีกเกอร์มี dose ได้หนึ่งแถวต่อรายการสารที่เลือก ผลสรุปมีหนึ่งแถวต่อรายการสารที่เลือก
5. สัญญาผู้ขายและราคาไม่เป็นตัวกำหนดรายการสารที่เลือก แต่สารแต่ละรายการในงานต้องอ้าง contract หนึ่งรายการที่ Site ตั้งไว้ก่อนเริ่มงาน และใช้ contract เดิมตลอดทุก round/beaker พร้อมเก็บ contract/price snapshot
6. ถ้าต้องการเปรียบเทียบสารคนละรายการในประเภทเดียวกัน ให้สร้าง Jar Test คนละงาน
7. หากต้องการใช้ราคา/contract อื่น ต้องเปลี่ยนค่าที่หน้าตั้งค่าของ Site ก่อนสร้างงาน Jar Test ไม่อนุญาตให้สลับ contract กลางงาน

## Consequences

- แบบร่าง Transaction เพิ่มเป็น 9 ตาราง โดยมี `jar_test_selected_chemicals` ระดับงาน
- การเลือกสัญญาและราคาเป็นอีกมิติหนึ่ง สัญญาหลายฉบับของสารเดียวกันไม่ทำให้ขัดกฎหนึ่งสารต่อประเภท แต่หนึ่งงานล็อก contract ที่เลือกไว้ตลอดงาน
- ต้องตรวจความสัมพันธ์ Site, งาน, รอบ, บีกเกอร์, สาร และสัญญาข้ามตารางใน physical schema หรือ backend
- วิธีแก้รายการสารหรือ contract ในงาน draft ที่มี dose แล้วต้องกำหนดรายละเอียดก่อน implementation; หลัง submit ห้ามแก้ผลเดิม

## Alternatives considered

- เลือกสารใหม่ได้ทุกรอบ: ไม่เลือก เพราะต้องการเปรียบเทียบ dose ของสารเดิมภายในงานเดียวตาม flow เดิม
- ใช้ `UNIQUE (beaker_id, site_chemical_contract_id)` เพียงอย่างเดียว: ไม่เลือก เพราะกันแค่สัญญาซ้ำ แต่ไม่กันสารคนละรายการในประเภทเดียวกัน

## Evidence

- คำยืนยันของเจ้าของโครงการวันที่ 25 กันยายน 2569 ต่อข้อเสนอให้ล็อกสารระดับงาน
- [Legacy Jar Test baseline](../../JarTest/legacy-jar-test-product-functional-spec-th.md) หัวข้อ 3 และ 10–11

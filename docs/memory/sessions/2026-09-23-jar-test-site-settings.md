# บันทึกการคุย: Jar Test Setting รายสถานี

วันที่จัดทำ: 2026-09-23

ประเภท: ข้อกำหนด TO-BE ที่เจ้าของโครงการอนุมัติ

## เป้าหมายและสถานะก่อนเริ่ม

สำรวจหน้าสร้างและหน้าดำเนินการ Jar Test ของ MAMIS ภายใต้ขอบเขต BU ALD และ Site AAA เพื่อพิจารณาว่าแนวคิด Jar Test Setting รายสถานีควรนำมาใช้ใน UMW2 หรือไม่

UMW2 ยังอยู่ในช่วง Discovery and domain design ไม่มี application code หรือ physical schema ที่อนุมัติ Legacy Jar Test specification เป็น AS-IS baseline แยกจากฟังก์ชันใหม่

## ข้อสังเกตจากหน้าจอ

- Jar Test Setting ของ MAMIS แสดงส่วนคุณสมบัติน้ำดิบ สารเคมี/ราคา และพารามิเตอร์ผลทดสอบ/Bound
- หน้าดำเนินการ Jar Test แสดงเงื่อนไขเวลาและ RPM ของขั้นตอนกวนและตกตะกอน
- จากหน้าจอไม่พบหลักฐานว่าเงื่อนไขการกวนและตกตะกอนถูกนำไปคำนวณ dose หรือผลผ่าน/ไม่ผ่าน; ข้อสังเกตนี้จำกัดอยู่ที่พฤติกรรมที่มองเห็นจาก UI
- ณ วันที่ 23 กันยายน ค่าและรายการใน MAMIS ยังไม่ได้รับอนุมัติให้คัดลอกเป็นค่าเริ่มต้น ต่อมาชุดพารามิเตอร์น้ำดิบ 9 รายการได้รับอนุมัติเมื่อ 25 กันยายน ดู [บันทึกการยืนยัน 9 ค่าเริ่มต้น](2026-09-25-jar-test-raw-water-defaults.md)

## คำยืนยันและข้อสรุปที่เจ้าของโครงการอนุมัติ

เจ้าของโครงการอนุมัติทั้งหกข้อ:

1. มี Jar Test Setting แยกตาม Site ไม่ใช้ค่าตั้งชุดเดียวทั้งระบบ
2. Setting กำหนดพารามิเตอร์และหน่วยของคุณสมบัติน้ำดิบ พารามิเตอร์ผลทดสอบและ Bound รวมถึงสารเคมีที่ใช้และราคา
3. Setting ของ Site ใช้กับ raw_unit ทุกแหล่งที่ mapping กับ Site นั้น; งาน Jar Test เลือกเฉพาะ raw_unit ที่ mapping กับ Site ของงาน
4. เงื่อนไขการกวนและตกตะกอนบันทึกเป็นข้อมูลของการทดลองแต่ละครั้ง ไม่รวมใน Site Setting และไม่ใช้คำนวณปริมาณสารหรือผลผ่าน/ไม่ผ่าน
5. งานแต่ละครั้งเก็บสำเนาค่าตั้งที่ใช้ หาก Site ยังไม่มีค่าตั้งที่จำเป็นให้แจ้งว่าต้องตั้งค่าก่อน และไม่ใช้ค่าตัวอย่างจาก MAMIS เป็นค่าเริ่มต้น
6. ข้อกำหนดนี้เป็น TO-BE แยกจาก legacy baseline

การอนุมัตินี้เป็นการอนุมัติขอบเขตผลิตภัณฑ์ ไม่ใช่การอนุมัติ physical schema, ค่าตั้งจริง, role/permission หรือ implementation details

## สิ่งที่ทำจริง

- เพิ่มข้อกำหนดผลิตภัณฑ์ TO-BE และ ADR-0003
- ปรับ CONTEXT, Target Domain Model และ Project State ตามคำยืนยัน
- ไม่แก้ legacy specification, ไม่สร้าง application code และไม่กำหนดค่าจาก MAMIS ให้ UMW2

## ข้อมูลที่ยังขาดและขั้นถัดไป

- รายการพารามิเตอร์ผลทดสอบของแต่ละ Site และการปรับรายการน้ำดิบเพิ่มเติมจาก 9 ค่าเริ่มต้น
- Bound จริงและวิธีเทียบค่าที่ขอบช่วง
- รายการสารเคมี หน่วยราคา และราคาจริง
- physical schema, snapshot/versioning, permissions, audit และ effective dates
- พฤติกรรม draft เมื่อ Site ยังตั้งค่าไม่ครบ
- โครงสร้างข้อมูลสภาวะการทดลอง รวมถึงเงื่อนไขการกวนและตกตะกอน

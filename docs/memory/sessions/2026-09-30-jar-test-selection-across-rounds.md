# บันทึกการตัดสินใจ: เปรียบเทียบ Jar ที่ผ่านข้ามทุกรอบ

วันที่จัดทำ: 2026-09-30

ประเภท: คำยืนยันโดยตรงของเจ้าของโครงการและข้อกำหนด Jar Test (TO-BE)

## เป้าหมายและสถานะก่อนเริ่ม

เจ้าของโครงการขอคุยเรื่องความหมายและการสรุปผลเมื่อหนึ่งงาน Jar Test มีหลายรอบ โดยข้อกำหนดที่มีอยู่แล้วคือหนึ่งงานเริ่มหนึ่งรอบและเพิ่มรอบได้ แต่ละรอบมี Jar หมายเลข 1–6 ของตนเอง และต้องกรอกผลครบทุก Jar ที่เลือกก่อน submit

## คำยืนยันของเจ้าของโครงการ

เจ้าของโครงการเห็นชอบแนวทางให้นำ Jar ที่ผ่านเกณฑ์จากทุกรอบของงานเดียวกันมาเปรียบเทียบร่วมกัน แล้วเลือก/แนะนำ Jar ที่มีต้นทุนสารเคมีรวมต่ำสุดเป็น Jar ที่ดีที่สุดของงาน

## ข้อกำหนดและผลต่อแบบข้อมูล

- การหา Jar ที่ดีที่สุดเป็นระดับงาน ไม่แยกผู้ชนะเฉพาะในแต่ละรอบ
- ผู้สมัครต้องเป็น Jar ที่ผลคุณภาพน้ำผ่านเกณฑ์ที่ตั้งไว้
- เปรียบเทียบต้นทุนสารเคมีรวมของผู้สมัครจากทุกรอบ และแนะนำรายการที่ต้นทุนต่ำสุด
- ค่า dose สรุปสุดท้ายยังแยกจาก dose ทดลองของ Jar ที่แนะนำ และอาจเป็นค่า manual ตามกติกาที่อนุมัติไว้
- ผลน้ำดิบและสารเคมีที่เลือกยังอยู่ระดับงาน; dose ผลคุณภาพ และสภาวะกวนของการทดลองยังแยกตามรอบ/Jar ตาม ADR-0004

## สิ่งที่ยังไม่กำหนด

- วิธีแสดงหรือให้ผู้ใช้ยืนยันเมื่อ Jar ที่ผ่านมีต้นทุนต่ำสุดเท่ากัน
- รายละเอียดหน้าจอของการเปรียบเทียบข้ามรอบ

การตัดสินใจนี้เป็นข้อกำหนดผลิตภัณฑ์ ไม่ได้เปลี่ยน physical DDL หรือเพิ่มตารางใหม่

# บันทึกการตัดสินใจ: เพิ่มรอบทดลองต่อเนื่องตามต้องการ

วันที่จัดทำ: 2026-09-30

ประเภท: คำยืนยันโดยตรงของเจ้าของโครงการและข้อกำหนด UX Jar Test (TO-BE)

## เป้าหมายและสถานะก่อนเริ่ม

หลังยืนยันให้เปรียบเทียบ Jar ที่ผ่านจากทุกรอบและเลือกตัวต้นทุนต่ำสุด ยังต้องกำหนดความหมายของการเพิ่มรอบใหม่และแนวทาง UI

## คำยืนยันของเจ้าของโครงการ

- รอบใหม่เป็นการทดลองต่อจากรอบก่อน
- ไม่สร้างหลายรอบค้างไว้ล่วงหน้า
- เมื่อจะทำรอบถัดไป ผู้ใช้กดคำสั่ง “เพิ่มรอบ” ตามแนวทาง UI ของ UMW
- ต้องกรอกผลคุณภาพของ Jar ทุกใบที่เลือกในรอบก่อนหน้าให้ครบก่อน จึงจะเพิ่มรอบใหม่ได้

## ผลต่อข้อกำหนด

- งานเริ่มต้นด้วยรอบแรกตามข้อกำหนดเดิม
- สร้างรอบถัดไปเมื่อผู้ใช้สั่งเพิ่มและพร้อมเริ่มการทดลองต่อ ไม่สร้างแถวรอบเปล่าล่วงหน้าหลายรอบ
- ปุ่มหรือคำสั่งเพิ่มรอบยังไม่พร้อมใช้งานจนกว่าผลของ Jar ที่เลือกทุกใบในรอบก่อนหน้าครบตามพารามิเตอร์ผลทดสอบ active; Jar ที่ไม่ได้เลือกไม่นับว่าขาดผล
- กติกาเปรียบเทียบ Jar ที่ผ่านจากทุกรอบเพื่อแนะนำตัวต้นทุนต่ำสุดยังคงเป็นระดับงาน
- รายละเอียดหน้าจออื่นนอกเหนือจากคำสั่งเพิ่มรอบและเงื่อนไขการเปิดใช้งานยังไม่กำหนด

## สิ่งที่ทำจริง

# บันทึกการสำรวจ: อ่าน Summary tab งาน Jar Test `22890`

วันที่: 2026-10-02

ประเภท: ข้อสังเกตจาก UI ระบบเดิม (AS-IS), อ่านอย่างเดียว

## เป้าหมาย

ต่อการ reverse engineer งาน Jar Test เดิม ID `22890` โดยอ่านแท็บสรุปผลที่ก่อนหน้านี้ยังไม่ได้เปิด

## สิ่งที่ทำ

- ใช้แท็บโดยตรงเพื่อเปิด `สารเคมีที่เลือก`, `ความเข้มข้น (PPM) ที่ใช้`, `ผลการทดสอบคุณภาพน้ำ` และ `สรุปผลการทดสอบ`; ไม่กด `ถัดไป` ซึ่ง UI เตือนว่าจะล็อกการแก้ไขขั้นก่อน
- ไม่กด `เลือก Jar ที่ดีที่สุด`, `กรอกสรุปผลทดสอบ` หรือ `เสร็จงาน`; ไม่แก้ไขหรือบันทึกข้อมูลใด
- งานยังแสดงสถานะ `งานที่กำลังทำ` ที่ Site `ระยอง`

## หลักฐานที่อ่านได้

- แท็บสรุปแสดง dose คลอรีนชนิดแก๊ส 3 PPM, PACl ชนิดน้ำ 25 PPM, พอลิเมอร์ประจุลบ 0.15 PPM และต้นทุนรวม 0.134 บาท/ลบ.ม.
- ค่านี้ตรงกับ Jar 3 ในผลรอบที่ 1; Jar 3 ผ่านและมีต้นทุนต่ำสุดเมื่อเทียบกับ Jar ที่ผ่าน 3–6 ซึ่งมีต้นทุน 0.134, 0.159, 0.184 และ 0.209 บาท/ลบ.ม.
- จึงเป็นหลักฐานสอดคล้องกับกติกา “เลือก Jar ที่ผ่านและต้นทุนต่ำสุด” แต่ยังพิสูจน์ไม่ได้ว่า UI คำนวณให้อัตโนมัติหรือ summary ถูกเลือก/กรอกไว้ก่อนแล้ว เพราะมีปุ่ม `เลือก Jar ที่ดีที่สุด` และ `กรอกสรุปผลทดสอบ` ให้ใช้งานด้วย
- ปริมาณสารที่เห็นยังตรงกับ `dose × 1000 ÷ stock concentration`; ต้นทุนรวมยังตรงกับผลรวม `dose × price ÷ 1000` ที่คำนวณเต็มความละเอียดก่อนแสดงผล

## ข้อจำกัดและขั้นถัดไป

- ห้ามทดลองปุ่มเลือก/กรอก/เสร็จงานบน ID `22890` เพราะเป็น Site `ระยอง`; การทดสอบที่เปลี่ยนข้อมูลใน UMW เดิมจำกัดไว้ที่ `สถานีผลิต Head Office`
- หากต้องยืนยันว่าเลือก Jar อัตโนมัติหรือไม่ ให้ใช้การอ่าน job ที่มีหลักฐานพอ หรือออกแบบงานทดสอบใหม่ภายใน Head Office หลังได้รับคำสั่ง; อย่าใช้ค่าหน้าจอนี้สรุปว่าระบบเลือกอัตโนมัติ
- ยังเปิดอยู่: สูตรแนะนำ Pre-chlorine/ด่างทับทิม, Bound ที่ใช้จริง, การตัดสินผลเมื่อบางพารามิเตอร์ว่าง, และวิธีปัดเศษแถวต้นทุนรายสาร

# External System Exploration Log

ใช้ไฟล์นี้บันทึกเฉพาะการสำรวจหรือทดลองที่ทำให้ข้อมูลใน UMW เดิมหรือ MAMIs เปลี่ยนแปลง เพื่อให้ตรวจสอบย้อนหลังได้

ห้ามบันทึก username, password, cookie, token, ข้อมูลส่วนบุคคล หรือข้อมูลลับลงในไฟล์นี้

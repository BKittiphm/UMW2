# ข้อกำหนด Jar Test Setting รายสถานี (TO-BE)

วันที่อนุมัติขอบเขต: 23 กันยายน 2569
สถานะ: อนุมัติขอบเขตผลิตภัณฑ์แล้ว; รายละเอียดข้อมูลและการพัฒนายังเปิดอยู่

## วัตถุประสงค์

กำหนดฟังก์ชันตั้งค่า Jar Test แยกตาม Site เพื่อให้แต่ละสถานีใช้พารามิเตอร์ เกณฑ์ผลทดสอบ และสารเคมีที่เกี่ยวข้องกับการทำงานของตนเอง โดยราคาและผู้ขายเก็บแยกตามสัญญาจัดซื้อ

เอกสารนี้เป็นข้อกำหนด TO-BE เพิ่มเติมจาก Legacy Jar Test specification ไม่ใช่การแก้ไขหรือแทนที่ baseline เดิม

## ข้อสรุปที่เจ้าของโครงการอนุมัติ

1. Jar Test Setting แยกตาม Site ไม่ใช้ค่าตั้งชุดเดียวทั้งระบบ
2. Site Setting กำหนดพารามิเตอร์และหน่วยของคุณสมบัติน้ำดิบ พารามิเตอร์ผลทดสอบและ Bound รวมถึงรายการสารเคมีที่ Site ใช้; ราคาและผู้ขายอยู่ในสัญญาจัดซื้อของสาร
3. Site Setting ใช้กับ raw_unit ทุกแหล่งที่ mapping กับ Site นั้น; งาน Jar Test เลือกได้เฉพาะ raw_unit ที่ mapping กับ Site ของงาน
4. เงื่อนไขการกวนและตกตะกอนบันทึกเป็นข้อมูลของการทดลองแต่ละครั้ง ไม่รวมใน Site Setting และไม่ใช้คำนวณปริมาณสารหรือผลผ่าน/ไม่ผ่านในขอบเขตที่อนุมัติ
5. งานแต่ละครั้งเก็บสำเนาค่าตั้งที่ใช้ไว้ตรวจย้อนหลัง หาก Site ยังไม่มีค่าตั้ง ระบบต้องแจ้งว่าต้องตั้งค่าก่อน และห้ามนำค่าตัวอย่างจาก MAMIS มาใช้เป็นค่าเริ่มต้น
6. ข้อกำหนดทั้งหมดเป็น TO-BE แยกจาก legacy baseline

## Functional requirements

| รหัส | ข้อกำหนด |
| --- | --- |
| JT-SET-001 | ผู้ดูแลต้องกำหนด Jar Test Setting แยกตาม Site ได้ |
| JT-SET-002 | Site Setting ระบุพารามิเตอร์และหน่วยที่ใช้กรอกคุณสมบัติน้ำดิบได้; ค่าที่ตรวจวัดจริงเป็นข้อมูลของงาน Jar Test แต่ละครั้ง |
| JT-SET-003 | Site Setting ระบุพารามิเตอร์ผลทดสอบและ Bound ได้; ระบบเป็นผู้คำนวณผ่าน/ไม่ผ่านตาม Bound ไม่ให้ผู้ใช้เลือกผลเอง |
| JT-SET-004 | Site Setting ระบุสารเคมีที่สถานีใช้ได้; ราคาและผู้ขายเก็บใน `site_chemical_contracts` เพื่อรองรับหลาย Vendor หรือหลายราคาต่อสารเดียวกัน |
| JT-SET-005 | Site Setting มีผลกับ raw_unit ที่ mapping กับ Site นั้นเท่านั้น และตัวเลือก water_source ของงานต้องจำกัดอยู่ในรายการ mapping ดังกล่าว |
| JT-SET-006 | ข้อมูล Jar Test ต้องเก็บสำเนาค่าตั้งที่ใช้ รวมถึงค่าที่จำเป็นต่อการอธิบายผลและต้นทุนย้อนหลัง; การแก้ค่าตั้งภายหลังต้องไม่เปลี่ยนงานเดิม |
| JT-SET-007 | หาก Site ยังไม่มีค่าตั้งที่จำเป็น ระบบต้องแจ้งว่าต้องตั้งค่าก่อนใช้งาน และห้ามใช้ค่าตั้งของ Site อื่นหรือค่าตัวอย่างจาก MAMIS โดยปริยาย |
| JT-SET-008 | เงื่อนไขการกวนและตกตะกอนบันทึกในข้อมูลการทดลองแต่ละครั้ง ไม่เป็นส่วนหนึ่งของ Site Setting และไม่ถูกใช้คำนวณ dose หรือผลผ่าน/ไม่ผ่าน |
| JT-SET-009 | การเพิ่ม Site Setting ต้องไม่เปลี่ยน AS-IS acceptance baseline; การเปลี่ยน workflow หรือการคำนวณจากเงื่อนไขการทดลองต้องมีข้อกำหนด TO-BE และการอนุมัติเพิ่มเติม |
| JT-SET-010 | เกณฑ์ผลทดสอบแต่ละชุดต้องมีได้หนึ่งรายการต่อ Site, Parameter และ Parameter Type; หากเปลี่ยนเกณฑ์ให้แก้รายการเดิมและใช้ค่าใหม่ทันที |
| JT-SET-011 | การประเมิน Bound ต้องรวมขอบเขต: ค่าที่เท่ากับ lower หรือ upper bound ถือว่าผ่าน; `lower_bound` ที่ว่างหมายถึง 0, `upper_bound` ที่ว่างหมายถึงไม่มีเพดานบน, ห้าม Bound ว่างทั้งคู่ และห้ามค่าติดลบ |
| JT-SET-012 | เกณฑ์ที่แก้ไขมีผลกับงานที่ยังไม่ submit; งานที่ submit แล้วต้องใช้ snapshot เกณฑ์เดิม หากต้องการใช้เกณฑ์ใหม่ต้องสร้าง Jar Test ใหม่ |
| JT-SET-013 | Jar Test ต้องบันทึก dose, ความเข้มข้นตั้งต้น, ปริมาตรน้ำ, ปริมาตรสารละลาย และราคาที่ snapshot ไว้ต่อบีกเกอร์ เพื่อคำนวณตาม C1V1 = C2V2 และตรวจสอบต้นทุนย้อนหลังได้ |
| JT-SET-014 | ระบบต้องเก็บ dose สรุปสุดท้ายแยกจาก dose รายบีกเกอร์ เพราะผู้ใช้สามารถยืนยันค่า final ที่ต่างจากบีกเกอร์ที่เลือกได้ |

## ขอบเขตข้อมูลและข้อห้าม

- water_source ของ Jar Test ยังคงหมายถึงรายการ raw_unit จริงที่ mapping กับ Site ไม่ใช่ประเภท wq_source หรือ asset type จากระบบอื่น
- ค่าจากหน้าจอ MAMIS ที่สำรวจเป็นเพียงข้อมูลตัวอย่าง ห้ามคัดลอกมาเป็น Bound ราคา หรือค่าเริ่มต้นของ UMW2 โดยไม่มีการยืนยันจากเจ้าของโครงการ
- การตั้งค่าเฉพาะ raw_unit ภายใน Site ยังไม่อยู่ในขอบเขตที่อนุมัติ; ข้อกำหนดปัจจุบันใช้ Site Setting เดียวครอบคลุม raw_unit ที่ mapping กับ Site นั้น
- รายการที่ระบบเดิมเรียกว่า Appearance Color ให้ผู้ตั้งค่าเลือก `Apparent Color` จาก `wq_parameter`; ระบบอ้างอิง `parameter_id` ที่เลือก ไม่จับคู่ชื่ออัตโนมัติ
- เอกสารนี้ไม่กำหนด physical schema, ชื่อตาราง, รูปแบบเวอร์ชัน, หน้าจอ, role/permission หรือค่าตั้งจริง

## รายละเอียดที่ยังต้องยืนยันก่อน implementation

- รายชื่อพารามิเตอร์และหน่วยน้ำดิบ รวมถึงพารามิเตอร์ผลทดสอบและ Bound ของแต่ละ Site
- รายการสารเคมี สัญญา ผู้ขาย หน่วยราคา และค่าราคาจริง
- วิธีเก็บและนำ Site Setting snapshot ไปผูกกับงานใน physical schema
- สิทธิ์ผู้แก้ไขและประวัติการเปลี่ยนแปลงของค่าตั้ง
- พฤติกรรมของ draft ที่เริ่มสร้างก่อน Site ตั้งค่าครบ; ห้ามใช้งานจริงโดยไม่มีการตั้งค่าที่จำเป็น
